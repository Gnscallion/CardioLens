系统能做什么

从原始心电信号到结构化报告的完整链路

  • 1
    选取心电记录与时间窗
    从 MIT-BIH 数据库中挑选记录，拖动滑块定位到感兴趣的时段
  • 2
    波形预览与专家标注对照
    分析前先查看波形，并叠加显示心电专家的原始标注位置
  • 3
    逐搏自动分类
    模型对窗口内每个心搏独立判别，输出五类概率与置信度
  • 4
    Grad-CAM 可解释性分析
    高亮模型判读依据的波形区间，通常是 QRS 波群所在位置
  • 5
    报告保存与历史回溯
    分析结果写入本地数据库，可随时回看或删除

    为什么选择心电信号分析

    区别于表格分类

    不是读取若干化验指标做二分类，而是直接处理 360 Hz 采样的原始时序信号， 需要模型自行从波形形态中学习 QRS 波群宽度、节律间期等判别特征。

    临床意义明确

    室性早搏、室上性早搏等异位搏动的识别是心电判读的核心任务之一， AAMI 五分类是国际通用的标准分类体系，任务定义清晰且有权威标注可比对。

    轻量可复现

    模型仅约 {% if metrics %}{{ '{:,}'.format(metrics.n_params) }}{% else %}10 万{% endif %} 参数，在普通 CPU 上约 18.3 分钟即可完成训练（16 轮触发早停），无需 GPU、 无需付费接口，整个系统在本地即可完整运行。
